# Money in Law
Static website prepared for https://moneyinlaw.github.io/.

Files: index.html, app.js, config.js, .nojekyll.
No build step or server runtime is required.

Assessment runs in browser memory. Refreshing clears its inputs.
LINE opens the public link configured in config.js.
The consultation form is intentionally disabled: no receiving endpoint or privacy contact is configured.
Google Fonts is an external dependency.

Publication has NOT been approved. After approval, use a new repository named
moneyinlaw.github.io under the confirmed Moneyinlaw account. GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root).
No custom domain or DNS changes are needed for the github.io address.
Review GitHub Pages commercial-use restrictions before publication.
Do not upload the original .git, .openai, credentials, logs or user submissions.
